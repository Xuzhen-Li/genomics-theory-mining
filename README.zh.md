# genomics-theory-mining

[English](README.md) | 中文

挖掘经典的基因组学或群体遗传学理论，并在现代数据上进行测试。
每次任务仅处理一个理论。阅读原始论文。这不是 `plant-lit-review` 的文献综述克隆版。

Skill: [`skills/genomics-theory-mining/SKILL.md`](skills/genomics-theory-mining/SKILL.md)
已填写的笔记：[`skills/genomics-theory-mining/theories/`](skills/genomics-theory-mining/theories/) 目录下每个理论对应一个文件夹（包含 `THEORY.md`）。[`SKILL.md`](skills/genomics-theory-mining/SKILL.md) 档案表作为索引。后续添加的内容（`reviews/`，`research/`，`scripts/`）放在该理论的文件夹中。
共有 145 个已填写的理论笔记。

## 安装

```bash
git clone https://github.com/Xuzhen-Li/genomics-theory-mining.git
cp -R genomics-theory-mining/skills/genomics-theory-mining ~/.cursor/skills/
```
